## 🚀 Live Demo
👉 **[Visit Vishnu Vardhan's 3D Portfolio](https://vishnuvardhan077.github.io/portfolio-mern/)**

An ultra-modern, high-performance **3D WebGL Developer Portfolio** built for **Vishnu Vardhan (`vishnuvardhan077`)** featuring interactive Three.js graphics, morphing 3D hero objects, an interactive 3D skill universe, 3D tilt project cards, live GitHub API integration, Web Audio synth FX, and glassmorphic dark UI.

---

## ✨ Features & Visual Highlights

- 🎨 **Morphing 3D WebGL Hero Canvas**:
  - Interactive Icosahedron / TorusKnot core geometry with vertex displacement lighting.
  - Wireframe mode toggle, particle explosions, and 3D geometry shape switcher.
  - Parallax 3D camera tracking with smooth mouse interpolation.
  - Dynamic typewriter title animation.

- 🌌 **3D Skill Constellation Universe**:
  - Orbitable 3D constellation featuring Vishnu's skills (**React.js**, **Node.js**, **Three.js & WebGL**, **MongoDB**, **Express**, **JavaScript ES6+**, **Java**, **Chrome Extensions**, **CSS3**, **Git**).
  - 3D layout toggles: `Sphere`, `Helix`, and `Grid`.
  - Click-to-inspect skill nodes with proficiency levels and linked project tags.

- 🧪 **3D Interactive Studio / Playground**:
  - Real-time 3D model inspector (adjust geometries, emissive colors, metalness, roughness, rotation speed, particle bursts).
  - Live 60 FPS counter overlay.

- 🚀 **3D Card Tilt Project Showcase & GitHub Live Sync**:
  - `perspective(1000px)` 3D gyro tilt cards for Vishnu's projects (`portfolio-mern`, `Student_Course_Management_System`, `cricket-extension`, `Mini-project`, `java-project`).
  - Real-time GitHub API fetcher for repo stars, descriptions, and repository stats.
  - Interactive 3D modal inspector.

- 🎵 **Web Audio Synth & 4 Sci-Fi Color Themes**:
  - Built-in Web Audio API synthesizer triggering sound effects for UI actions.
  - Color themes: `Cyberpunk Cyan`, `Neon Violet`, `Matrix Emerald`, `Solar Gold`.

## 🛠️ Tech Stack

- **Core**: JavaScript (ES6+), HTML5, CSS Custom Properties (Vanilla CSS)
- **3D Engine**: Three.js, WebGL Shaders, Orbit Controls
- **Bundler & Tooling**: Vite v6
- **Icons & Audio**: FontAwesome 6, Web Audio API Synth

## 💻 Local Setup & Development

1. **Clone the repository**:
   ```bash
   git clone https://github.com/vishnuvardhan077/portfolio-mern.git
   cd portfolio-mern
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start local development server**:
   ```bash
   npm run dev
   ```

4. **Build production bundle**:
   ```bash
   npm run build
   ```
